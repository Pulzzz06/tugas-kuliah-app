Dokumentasi Teknis Aplikasi

1. Git & GitHub

Digunakan sebagai Version Control System (VCS) untuk mencatat riwayat perubahan kode melalui commit, mengelola eksperimen fitur secara terpisah menggunakan branch, menggabungkan kode melalui Pull Request & Merge, serta menangani bentrokan baris kode (merge conflict).

2. npm & Package Management

Node Package Manager (npm) mengelola pustaka proyek melalui package.json. dependencies berisi pustaka yang dibutuhkan saat aplikasi berjalan di produksi, sedangkan devDependencies (seperti TypeScript dan Vite) hanya dibutuhkan saat tahap pengembangan. Versi pustaka diatur menggunakan Semantic Versioning (MAJOR.MINOR.PATCH).

3. TypeScript

Menambahkan sistem static typing di atas JavaScript. Aplikasi ini menerapkan primitive types (string, number, boolean), Array, Interface (TugasKuliah), Union & Type Alias (TaskStatus), serta Generics (StorageWrapper<T>) untuk mencegah bug tipe data sejak penulisan kode.

4. Vite, Compiler, Transpiler, dan Bundler

Browser tidak dapat mengeksekusi file TypeScript (.ts) secara langsung. Di sinilah peran alat bantu build: Compiler/Transpiler (`tsc` dan `esbuild` pada Vite) memeriksa tipe data dan menerjemahkan kode TypeScript menjadi JavaScript standar yang dipahami browser. Selanjutnya, Bundler (Rollup pada saat `npm run build`) menggabungkan, mengoptimalkan, dan memperkecil (minify) seluruh modul HTML, CSS, dan JS menjadi aset statis siap unggah di folder dist/.

5. Environment Variables (.env)

Menyimpan konfigurasi aplikasi di luar source code utama. Variabel publik diawali VITE_ agar dapat dibaca melalui import.meta.env, sedangkan file .env dimasukkan ke .gitignore agar kredensial rahasia atau API key tidak bocor ke repositori publik GitHub.
